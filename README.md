## 🔥 正在做

**[ACE for OpenWrt](https://github.com/bluepebblex-dev/openwrt-ace)** — 一个把 Cloudflare WARP 变成全屋出口的 LuCI 插件。

> 装上、点一下、整屋出国 —— 不需要订阅、不需要配置、不需要懂行。

[![release](https://img.shields.io/github/v/release/bluepebblex-dev/openwrt-ace?style=flat-square&color=2ea043)](https://github.com/bluepebblex-dev/openwrt-ace/releases)
[![CI](https://github.com/bluepebblex-dev/openwrt-ace/actions/workflows/ci.yml/badge.svg)](https://github.com/bluepebblex-dev/openwrt-ace/actions/workflows/ci.yml)
[![license](https://img.shields.io/github/license/bluepebblex-dev/openwrt-ace?style=flat-square)](https://github.com/bluepebblex-dev/openwrt-ace/blob/main/LICENSE)

| 做了什么 | 怎么做的 |
|---|---|
| **零配置全屋出口** | 两个 ipk 装完即用，大圆钮点一下：本地注册 WARP 账号 → 全量扫端点实测延迟/速率 → 自动挑最优 → 渲染配置 → 起 TUN → 验数据面 |
| **不靠任何订阅** | 流量直达 Cloudflare WARP，不经第三方中转；无外部面板、无云端控制端 |
| **看得见的诊断** | 连接过程分阶段可视化；首页 24h 网络质量曲线自动标注「本地拥塞 / 跨境波动」；一键测四站真实连通性 |
| **轻到可以忽略** | 下载包 ≈ 5 MB，运行时 ≈ 100 MB，256 MB 内存的路由器就能跑 |

技术栈：`Go` · `Lua` · `OpenWrt` · `mihomo` · `Cloudflare WARP (MASQUE / WireGuard / AmneziaWG)`
